# Contracts

Foundry project for the on-chain verifier. `src/Verifier.sol` is generated by EZKL (`artifacts/Verifier.sol`) and exposes `Halo2Verifier.verifyProof(bytes proof, uint256[] instances)`.

```powershell
forge build --sizes
anvil
forge create src/Verifier.sol:Halo2Verifier --rpc-url http://127.0.0.1:8545 --private-key <KEY> --broadcast
```

Phase 4 of `main.ipynb` runs these steps and calls the verifier with the proof.
